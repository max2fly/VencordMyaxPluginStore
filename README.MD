# VencordPluginStore

Appstore, but for third party plugins, mostly written or modified by me, as well as some recommendations which are not part of base vencord.

## Prerequisite
Vencord custom install:
See https://docs.vencord.dev/installing/

## Installation
See https://docs.vencord.dev/installing/custom-plugins/

For the "Adding your plugin" step, you can add the plugin by running the command:
```git clone https://github.com/max2fly/VencordMyaxPluginStore.git```
(assuming you are already cd'd into vencord/src/userplugins)
